# 운동 기록

운동 중 땀에 젖은 손으로도 탭만으로 세트 무게/횟수를 기록하는 개인용 웹앱.

## 아이폰에 설치하기

1. Safari로 앱 URL 접속
2. 공유 버튼 → "홈 화면에 추가"
3. 홈 화면 아이콘으로 전체화면 앱처럼 실행됨

## 사용 흐름

종목 탭 → 세트수 탭 → (무게 스테퍼 확인 → 횟수 스테퍼 확인) 반복 → 저장하고 홈으로

- 다음 세트는 이전 세트 무게/횟수가 기본값으로 채워짐 (같은 무게로 계속하는 경우 확인만 계속 탭하면 됨)
- 다음 운동 세션에서 같은 종목을 고르면 지난번 마지막 세트 무게/횟수가 기본값으로 채워짐
- 처음 하는 종목은 종목설정에서 지정한 시작 무게가 기본값으로 채워짐 (기본 20kg, 종목마다 다르게 설정 가능)
- 요약 화면에서 세트를 탭하면 수정 가능

## 홈 화면 메뉴

- **운동일정**: 달력에서 기록한 날짜 확인, 날짜 탭하면 그날 기록 열람
- **종목설정**: 종목 추가/삭제, 종목별 시작 무게 설정
- **AI 코칭**: 최근 2주 기록을 바탕으로 Gemini가 작성하는 주간 총평 + 다음 주 제안 (아래 설정 필요)
- ⚙(좌상단): 앱 제목, AI 코칭 키, GitHub 백업 설정

## AI 코칭 설정 (선택, 무료)

1. https://aistudio.google.com/apikey 에서 Google 계정으로 무료 API 키 발급
2. 앱 ⚙ 설정 → "Gemini API Key"에 붙여넣고 저장
3. 홈 → "AI 코칭" → "AI 코칭 생성하기" 탭
4. 최근 2주 기록이 있어야 코칭이 생성됨 (기록이 하루치뿐이면 아직 준비 중이라고 안내)
5. 하루 한 번 캐시되며, 언제든 "다시 생성"으로 새로 받을 수 있음

## GitHub 자동 백업 설정 (선택)

1. GitHub에서 별도 **private** 저장소 `workout-data`를 만든다 (기록은 공개 저장소인 이 앱 코드와 분리해서 비공개로 보관)
2. GitHub → Settings → Developer settings → Fine-grained personal access tokens → Generate new token
3. Repository access: **workout-data 저장소만** 선택
4. Permissions: **Contents → Read and write** 만 부여
5. 앱의 ⚙(설정) 화면에서 토큰/사용자명/저장소명(`workout-data`) 입력 후 저장
6. 운동을 저장할 때마다 `log.json`에 자동으로 백업됨

토큰은 이 기기의 브라우저 localStorage에만 저장되며 다른 곳으로 전송되지 않습니다 (GitHub API 호출 외).

## 백업한 데이터 불러오기 (새 기기 / 복원)

새 기기에서 이어서 쓰거나, 브라우저 데이터가 초기화됐을 때 GitHub에 백업된 기록을 다시 불러올 수 있다.

1. 앱 ⚙(설정) 화면에서 GitHub 토큰/사용자명/저장소명을 위와 동일하게 입력하고 저장 (새 기기라면 여기서부터 시작)
2. "GitHub에서 불러오기 (이 기기 덮어쓰기)" 버튼 탭
3. 확인 창에서 계속하면 GitHub의 `log.json` 내용으로 이 기기의 운동 기록을 덮어씀

⚠️ 이 기기에만 있고 아직 GitHub에 동기화되지 않은 기록이 있다면 불러오기 시 사라지니, 먼저 "지금 GitHub 동기화"로 최신 상태를 올려둔 뒤 불러오는 걸 권장.
